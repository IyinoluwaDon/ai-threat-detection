# AI Threat Detection Engine

Real-time web attack detection: Nginx access logs go in, scored alerts come out.
Regex rules catch known patterns, an ML ensemble catches what the rules miss.

**Status:** in progress (Day 4 of 7).

## Rules-only baseline (synthetic dataset, 6000 rows)

| Traffic | Detection |
|---|---|
| Benign false positives | 0.0% |
| Classic attacks | 100.0% |
| Evasive attacks | 0.0% |
| Recon / scanning | 0.0% |

Rules are precise but blind to evasion and recon. The ML layer is built to close that gap.

## Run

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.stub_server          # target, writes logs/access.log
python -m app.pipeline logs/access.log
```

## Limitations

The dataset is synthetic (generated by `app/gen_dataset.py`), so metrics describe that
distribution, not real-world traffic.
